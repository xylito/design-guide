## 🚀 How to Feed into AI Agents

### 1. Claude Code (`CLAUDE.md`)
Copy the `🤖 AI Agent System Prompt Injection` block from the desired `DESIGN.md` into your project's `CLAUDE.md` file.

### 2. Cursor (`.cursorrules` or `.cursor/rules/`)
Create a `.cursorrules` file in your repository root and paste the contents of `DESIGN.md`.

### 3. Gemini CLI / Antigravity
Save the `DESIGN.md` into your workspace root or `.agents/rules/DESIGN.md` to automatically enforce the design tokens.
